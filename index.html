🐙 GitHub-a Yerləşdirmə

Bu fayl tək başına tam işləkdir (Single-File HTML). Heç bir backend server və ya Node.js quraşdırmadan pulsuz olaraq GitHub Pages-də işləyir!

  1. GitHub-da yeni repo açın və bu faylı index.html adı ilə repoya əlavə edin.
  2. Repo parametrlərinə (Settings → Pages) daxil olun.
  3. Source bölməsindən Deploy from a branch seçin, Branch olaraq main və / (root) qovluğunu seçib Save edin.
  4. 1-2 dəqiqə sonra saytınız https://istifadəçi.github.io/repo/ ünvanında aktiv olacaq!
💡 Qeyd: Saytda KROXY AI heç bir server olmadan birbaşa ziyarətçilərə cavab verir. Heç bir açar yerləşdirməyə ehtiyac yoxdur.
